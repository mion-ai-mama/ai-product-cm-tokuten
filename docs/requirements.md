## 3. 競合ページの参照範囲

競合特典ページ（Utage会員ページ）は「構成の型」だけを参考にした（できること→手順→コピー用プロンプト）。文章・プロンプト本文・CTAは転載していない。プロンプト①②は出典リール台本（本人の言葉）、③はユーザーが実際にGeminiへ貼ったプロンプト（原文のまま）。

## 4. 公式情報（2026-11-12時点・Gemini公式ヘルプ）

- 個人アカウントでの利用にはGoogle AIプランが必要／動画は3〜10秒（AI Ultraは15秒まで）
- パソコン: 公式ヘルプは「サイドバー→動画を作成」。**実画面（ユーザー提供スクショ 2026-11-12）では、入力欄の「＋」を押すメニューの中に「動画を作成」がある**。ページは実画面に合わせて記載。画像は最大5枚・動画は1本まで添付可
- 生成には数分かかり、生成中は同じチャットを続けられない
- ダウンロード: 動画下のアイコン →「動画をダウンロード」
- 利用規約・権利: 画像の権利を持っていること／公開・使用前に自分で確認すること

## 5. ページに書かない／書くこと

- 収入・仕事の獲得を約束しない（金額は載せない）。最終CTAに「収入や収益が得られることを保証するものではありません」
- 「確認していません」等の未確認の開示は読者向けに書かない（内部記録は docs/SCOPE_PROGRESS.md）
- 人物はバナーの本人イラスト（2026-11-12にユーザーが作成した新イラスト・スマホのポーズ）のみ。絵コンテ内の人物はAI生成の作例であり本人ではない
- バナーは Codex の image_gen で生成（2026-11-12）。参照に「背景を切り抜いた本人イラスト」「完成CMの実フレーム3枚」「レイアウト案」を渡し、人物は描き直させない。人物は背景つきのまま貼らない（周りと合わないため）。ボトルのラベル文字（PARFUM OIL / Hair&Body / 3.4 fl oz / 100ml）が崩れていないか必ず確認する
